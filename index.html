線性內插查 N(x)

Black‑Scholes 必用 · 試算工具
為什麼要內插? 常態分配表只列到小數第 2 位(如 N(0.62)、N(0.63)), 但你算出的 d₁、d₂ 通常有 4 位(如 0.6278)。 內插就是「在兩個表值之間,照比例抓中間的值」。
內插公式
N(x) = N(x₀) + w × [ N(x₁) − N(x₀) ] x₀ = 把 x 無條件捨去到小數第 2 位 (下界) x₁ = x₀ + 0.01 (上界) w = (x − x₀) / 0.01 = x 的第 3、4 位小數 (權重 0~1)
課本範例
正值:N(0.6278) = N(0.62) + 0.78×[N(0.63)−N(0.62)] = 0.7324 + 0.78×(0.7357−0.7324) = 0.7350
負值:N(−0.1234) = N(−0.12) − 0.34×[N(−0.12)−N(−0.13)] = 0.4522 − 0.34×(0.4522−0.4483) = 0.4509
小技巧:負值也能用對稱性 N(−x) = 1 − N(x) 反查正表,結果一樣。

資金成本與 WACC

Cost of Capital · CAPM · 加權平均資金成本
13.1用 CAPM 求權益成本
題目
某公司普通股的 β 係數為 1.07。目前無風險利率為 3.4%,市場投資組合的預期報酬率為 11%。請以資本資產定價模型(CAPM)計算該公司的權益資金成本 RE。
觀念
CAPM 說明:股東願意承擔風險,因此要求的報酬 = 完全無風險時能拿到的報酬(Rf),再加上「承擔這檔股票系統風險」的補償。補償 = β ×(市場風險溢酬)。β 衡量個股報酬相對整體市場波動的敏感度:β=1 與市場同步,β>1 波動比市場大。市場風險溢酬 = 市場報酬 − 無風險利率,代表「多承擔一單位市場風險」的平均報酬。
公式
RE = Rf + β × ( Rm − Rf ) Rf = 無風險利率 Rm = 市場預期報酬 β = 系統風險係數
詳解
  1. 先算市場風險溢酬(market risk premium):
    Rm − Rf = 11% − 3.4% = 7.6%
    意義:市場整體比無風險資產多賺 7.6%,這是「每一單位 β」的補償。
  2. 乘上本股票的 β,得到這檔股票應得的風險補償:
    β ×(Rm−Rf)= 1.07 × 7.6% = 8.132%
  3. 加回無風險利率,得權益成本:
    RE = 3.4% + 8.132% = 11.532%

答案RE = 11.5320% ≈ 11.53%
13.5計算加權平均資金成本 WACC
題目
某公司的目標資本結構為:權益佔總市值 70%、負債佔 30%。權益資金成本 RE = 11.3%,稅前負債成本 RD = 5.9%,公司稅率 Tc = 23%。請計算 WACC。
觀念
WACC 是公司「整體」的資金成本:把權益與負債各自的成本,依其市值權重加權平均。關鍵點:利息費用可以抵稅,公司實際負擔的負債成本是稅後的 RD(1−Tc);而股利不能抵稅,所以權益成本不打折。
公式
WACC = (E/V)·RE + (D/V)·RD·(1−Tc) E/V = 權益權重 D/V = 負債權重 Tc = 稅率
詳解
  1. 權益部分的貢獻 = 權益權重 × 權益成本:
    0.70 × 11.3% = 7.91%
  2. 把負債成本變成稅後(因為利息抵稅):
    RD(1−Tc) = 5.9% ×(1−0.23) = 5.9% × 0.77 = 4.543%
  3. 負債部分的貢獻 = 負債權重 × 稅後負債成本:
    0.30 × 4.543% = 1.3629%
  4. 兩者相加得 WACC:
    WACC = 7.91% + 1.3629% = 9.2729%

COMP 模式
0.7×11.3+0.3×5.9×0.77=
顯示 9.2729
答案WACC = 9.2729% ≈ 9.27%
13.7由 WACC 反推資本結構權重
題目
某公司 WACC = 8.4%,權益成本 RE = 11%,稅前負債成本 RD = 5.8%,稅率 Tc = 25%。求負債佔總值比 D/V、權益佔總值比 E/V,以及負債權益比 D/E。
觀念
WACC 公式裡有兩個未知權重,但 E/V + D/V = 1,所以只剩一個未知數。設 D/V = x,則 E/V = 1−x,代入 WACC 方程式解一元一次方程式即可。
公式
WACC = (1−x)·RE + x·RD·(1−Tc) ,其中 x = D/V E/V = 1 − x ; D/E = (D/V) ÷ (E/V)
詳解
  1. 設未知數並代入:設 D/V = x,E/V = 1−x。稅後負債成本 = 5.8%×(1−0.25) = 5.8%×0.75 = 4.35%。
    8.4 = (1−x)(11) + x(4.35)
  2. 展開化簡:
    8.4 = 11 − 11x + 4.35x
    8.4 = 11 − 6.65x
  3. 解 x:
    6.65x = 11 − 8.4 = 2.6
    x = 2.6 / 6.65 = 0.3910 → 即 D/V = 39.10%
  4. 算其餘權重:
    E/V = 1 − 0.3910 = 0.6090
    D/E = 0.3910 / 0.6090 = 0.6420
FC-100V 按法(解出 x 後算 D/E)
COMP 模式
(11−8.4)÷(11−5.8×0.75)=
顯示 0.3910 → 即 D/V
答案D/V = 0.3910 · E/V = 0.6090 · D/E = 0.6420
13.10反求稅前負債成本與權益成本
題目
某公司目標負債權益比 D/E = 0.65,稅率 23%,WACC = 10.4%。(a) 若權益成本 RE = 14%,求稅前負債成本 RD。(b) 若已知稅後負債成本為 5.8%,求權益成本 RE。
觀念
同一條 WACC 公式,已知其他項就能反解任一項。先把 D/E 換成權重:D/E=0.65 表示每 1 元權益配 0.65 元負債,總共 1.65 → D/V = 0.65/1.65,E/V = 1/1.65。
公式
WACC = (E/V)RE + (D/V)RD(1−Tc) D/V = 0.65/1.65 = 0.3939 E/V = 1/1.65 = 0.6061
詳解 (a) 求稅前 RD
  1. 算權重:D/V = 0.65/1.65 = 0.3939,E/V = 1/1.65 = 0.6061
  2. 代入 WACC 公式:
    10.4 = 0.6061×14 + 0.3939×RD×(1−0.23)
    10.4 = 8.4848 + 0.3939×0.77×RD
    10.4 = 8.4848 + 0.30333·RD
  3. 移項求解:
    0.30333·RD = 10.4 − 8.4848 = 1.9152
    RD = 1.9152 / 0.30333 = 6.3137%
詳解 (b) 求 RE(已知稅後負債成本 5.8%)
  1. 稅後負債成本已給 = 5.8%,直接代入,不需再 ×(1−Tc):
    10.4 = 0.6061×RE + 0.3939×5.8
  2. 計算負債貢獻:0.3939×5.8 = 2.2848
    10.4 = 0.6061·RE + 2.2848
  3. 移項求解:
    0.6061·RE = 10.4 − 2.2848 = 8.1152
    RE = 8.1152 / 0.6061 = 13.39%
答案(a) 稅前 RD ≈ 6.3137% ≈ 6.31% · (b) RE ≈ 13.39%
13.13用各專案的 CAPM 報酬取代單一門檻
題目
某公司一律用 12% 作為投資門檻。無風險利率 4%,市場報酬 12%。四個專案的 β 與 IRR 為:
W(β=0.83)、X(β=0.92)、Y(β=1.09)、Z(β=1.35)。(a) 用 12% 門檻會接受哪些?(b) 用各自 CAPM 要求報酬應接受哪些?(c) 用單一門檻會造成什麼錯誤?
觀念
不同專案的風險(β)不同,合理的門檻應該因案而異:每個專案都用自己的 β 算出 CAPM 要求報酬,專案 IRR > 自身要求報酬才接受。若全公司都用同一個門檻(12%),會「高風險的爛案被誤收、低風險的好案被誤拒」。
公式
要求報酬 = Rf + β(Rm−Rf) = 4% + β×8%
詳解 — 先算每個專案各自的 CAPM 要求報酬
  1. 市場風險溢酬 = 12% − 4% = 8%
  2. W:4% + 0.83×8% = 4% + 6.64% = 10.64%
  3. X:4% + 0.92×8% = 4% + 7.36% = 11.36%
  4. Y:4% + 1.09×8% = 4% + 8.72% = 12.72%
  5. Z:4% + 1.35×8% = 4% + 10.80% = 14.80%
專案βCAPM 要求報酬IRR vs 12%IRR vs 自身門檻
W0.8310.64%低於 12%低於 10.64%
X0.9211.36%低於 12%高於 11.36% ✓
Y1.0912.72%高於 12%高於 12.72% ✓
Z1.3514.80%高於 12%低於 14.80%
判斷
  1. (a) 用 12% 門檻 → 接受 IRR > 12% 的:Y、Z
  2. (b) 正確做法(IRR > 各自 CAPM) → 接受:X、Y
  3. (c) 兩者差異 → 12% 門檻的錯誤:
    • X 被錯誤拒絕:X 的 IRR 雖低於 12%,卻高於它自己的要求報酬 11.36%,本該接受。
    • Z 被錯誤接受:Z 的 IRR 雖高於 12%,卻低於它自己應有的 14.80%,風險沒被充分補償,本該拒絕。
答案(a) 接受 Y, Z · (b) 接受 X, Y · (c) X 被錯拒、Z 被錯收

18.1全權益最高買價 + APV
題目
Benton 公司考慮購入一支 25 輛車的車隊,以直線法折舊 5 年(殘值 0)。此車隊每年產生稅前折舊前利潤(PBTD)$225,000,稅率 21%,適用折現率(全權益權益成本)14%。(a) 若以全權益融資,公司最高願意付多少買價?(b) 若以 $700,000 購入,並舉借 $450,000、利率 8% 的「只付息」負債,求此投資的 APV。
觀念
APV(調整現值) = ① 假裝全用權益的基礎 NPV(Base NPV)+ ② 融資帶來的副效果(主要是利息稅盾的現值)。
每年的無槓桿現金流 UCF = 稅後營業利潤 + 折舊稅盾。(a) 的小技巧:折舊 = 買價/5,買價本身是未知數,所以要把買價 P 當變數,令 Base NPV = 0 解出最高價。
公式
UCF = PBTD·(1−Tc) + 折舊·Tc APV = −成本 + UCF·PVIFA(RE,n) + 年利息稅盾·PVIFA(RD,n) 年利息稅盾 = 負債 × 利率 × Tc
詳解 (a) 全權益最高買價
  1. 查年金現值因子 PVIFA(14%, 5) = 3.4331
  2. 把 UCF 寫成 P 的函數(折舊 = P/5):
    UCF = 225,000×(1−0.21) + (P/5)×0.21 = 177,750 + 0.042P
  3. 令 Base NPV = 0(買到「剛好不賺不賠」的最高價):
    P = UCF × PVIFA = (177,750 + 0.042P) × 3.4331
  4. 展開:
    P = 177,750×3.4331 + 0.042×3.4331×P
    P = 610,233.5 + 0.14419P
  5. 移項解 P:
    P − 0.14419P = 610,233.5
    0.85581P = 610,233.5
    P = 610,233.5 / 0.85581 = $713,048(用全精度因子約 $713,043)
詳解 (b) APV(買價 $700,000、負債 $450,000)
  1. 折舊 = 700,000 / 5 = 140,000/年
  2. 無槓桿現金流 UCF = 225,000×0.79 + 140,000×0.21 = 177,750 + 29,400 = 207,150
  3. 基礎 NPV(以 14% 折現):
    Base NPV = −700,000 + 207,150 × 3.4331 = −700,000 + 711,167 = $11,167
  4. 每年利息稅盾 = 450,000 × 8% × 21% = 36,000 × 0.21 = 7,560
  5. 稅盾現值(只付息,用負債利率 8% 折現;PVIFA(8%,5)=3.9927):
    7,560 × 3.9927 = $30,185
  6. APV = Base NPV + 稅盾現值 = 11,167 + 30,185 = $41,352
FC-100V 按法(年金現值因子 PVIFA)
CMPD 模式 P/Y=1 C/Y=1
n=5→I%=8→PMT=−1→FV=0→SOLVE→PV
PV 取絕對值 = 3.9927(8%);同法 I%=14 得 3.4331
答案(a) 最高買價 ≈ $713,048 · (b) APV ≈ $41,352
18.5用 unlevered β 還原各公司 RE
題目
同產業的無槓桿(資產)βA = 1.05。無風險利率 3.2%,市場風險溢酬 8.1%,稅率 21%,假設負債 β = 0。North 部門 D/E ≈ 0.5135,South 部門 D/E ≈ 1.9474。求兩部門各自的權益成本 RE。
觀念
負債會放大股東承擔的風險,所以 levered 的權益 β 會比資產 β 大。先用 levering 公式,把資產 β 依各部門的 D/E「加槓桿」還原成權益 βE,再代入 CAPM 求 RE。
公式
βE = βA · [ 1 + (1−Tc)·(D/E) ] (假設 β_debt = 0) RE = Rf + βE·(市場風險溢酬)
詳解 — North 部門(D/E = 0.5135)
  1. 加槓桿求 βE:
    βE = 1.05 × [1 + (1−0.21)×0.5135] = 1.05 × [1 + 0.79×0.5135]
    = 1.05 × [1 + 0.4057] = 1.05 × 1.4057 = 1.4760
  2. 代入 CAPM:
    RE = 3.2% + 1.4760 × 8.1% = 3.2% + 11.9556% = 15.16%
詳解 — South 部門(D/E = 1.9474)
  1. 加槓桿求 βE:
    βE = 1.05 × [1 + 0.79×1.9474] = 1.05 × [1 + 1.5384] = 1.05 × 2.5384 = 2.6653
  2. 代入 CAPM:
    RE = 3.2% + 2.6653 × 8.1% = 3.2% + 21.589% = 24.79%
答案North RE ≈ 15.16% · South RE ≈ 24.79%
18.6補貼貸款的 NPV(含發行成本)
題目
某公司取得一筆 10 年期、年利率 5.8% 的貸款,毛額(gross proceeds)$5,300,000,發行成本為毛額的 2.5%,稅率 21%。利息每年支付、本金到期一次還清。(a) 不考慮發行成本時,此貸款的 NPV?(b) 把發行成本(分 10 年攤銷)納入後,NPV?
觀念
若貸款以「市場公平利率」計價,把稅後的利息與本金用稅後負債成本折現,NPV 會剛好 = 0(沒佔便宜也沒吃虧)。真正讓 NPV 變負的是發行成本:公司只實拿毛額 − 發行成本,卻要按全額付息還本;發行成本可分年攤銷產生少量稅盾,但抵不過成本本身。
公式
稅後利率 = RD(1−Tc) 稅後利息 = 本金·RD·(1−Tc) NPV = +毛額 − 稅後利息·PVIFA − 本金·PVIF (以稅後利率折現) 發行成本年攤銷稅盾 = (發行成本/年數)·Tc
詳解 (a) 不含發行成本
  1. 稅後負債利率 = 5.8%×(1−0.21) = 5.8%×0.79 = 4.582%
  2. 每年稅後利息 = 5,300,000 × 5.8% × 0.79 = 307,400 × 0.79 = 242,846
  3. 用 4.582% 折現(PVIFA≈7.8809,PVIF≈0.6389):
    NPV = 5,300,000 − 242,846×7.8809 − 5,300,000×0.6389
    = 5,300,000 − 1,913,838 − 3,386,170 ≈ $0
  4. 結論:公平定價的貸款,稅後現金流以稅後成本折現,NPV = 0。
詳解 (b) 含發行成本
  1. 發行成本 = 2.5% × 5,300,000 = 132,500(期初一次付出)
  2. 每年攤銷 = 132,500 / 10 = 13,250 → 稅盾 = 13,250 × 0.21 = 2,782.50/年
  3. 稅盾現值 = 2,782.50 × 7.8809 = 21,929
  4. 合計 NPV = (a 的 0) − 發行成本 + 稅盾現值:
    = 0 − 132,500 + 21,929 = −$110,571
答案(a) NPV = $0 · (b) NPV ≈ −$110,571
18.7全權益專案的 NPV
題目
Jimenez 公司為全權益公司,權益成本 11.2%(題目另給無風險利率 3.4%)。一個專案需投資 $11.6M,以直線法折舊 6 年,每年「營收 − 費用」= $3.5M,稅率 23%。求此專案 NPV 並判斷是否接受。

    = 3,500,000×(1−0.23) + 1,933,333.33×0.23

  4. NPV:
    = −11,600,000 + 3,139,666.67 × 4.2063 = −11,600,000 + 13,206,308 = +$1,606,308
  5. 判斷:NPV > 0 → 接受。

18.8永續現金流 + WACC
題目
National Electric 評估一個需投資 $41M 的專案,可產生永續的無槓桿現金流 $3.1M/年。稅前負債成本 5.1%、權益成本 10.3%、目標負債佔比 D/V = 60%、稅率 21%。用 WACC 求 NPV。
觀念
無槓桿永續現金流的現值 = 現金流 ÷ WACC(永續年金公式)。WACC 已內含負債稅盾的效果,所以直接用它折現即可。
公式

26.6營運循環與現金循環
題目

觀念
營運循環 = 存貨期間 + 應收期間,即「進貨 → 賣出 → 收到現金」的總天數。現金循環 = 營運循環 − 應付期間,即「真正自己掏錢」的天數(因為應付帳款讓你延後付供應商)。期間 = 平均餘額 ÷(每日成本或銷貨)。
公式
存貨期間 = 平均存貨 ÷ (COGS/365) 應收期間 = 平均AR ÷ (銷貨/365) 應付期間 = 平均AP ÷ (COGS/365) 營運循環 = 存貨期間 + 應收期間 現金循環 = 營運循環 − 應付期間
詳解
  1. 存貨期間 = 14,025 ÷ (79,218/365) = 14,025 ÷ 217.036 = 64.6207 天
  2. 應收期間 = 6,203.5 ÷ (143,187/365) = 6,203.5 ÷ 392.293 = 15.8134 天
  3. 營運循環 = 64.6207 + 15.8134 = 80.4341 天
  4. 應付期間 = 8,535 ÷ (79,218/365) = 8,535 ÷ 217.036 = 39.3253 天
  5. 現金循環 = 80.4341 − 39.3253 = 41.1088 天
答案營運循環 ≈ 80.43 天 · 現金循環 ≈ 41.11 天

  3. 合併後總價值 = 53 + 31.5 + 14.5 = $99M

  5. (b) NPV:現金 = 46 − 44.5 = $1.5M;股票 = 46 − 39.6 = $6.4M
  6. (c) 股票 NPV($6.4M)> 現金($1.5M)→ 選股票收購。

29.6換股併購的 EPS 與本益比

觀念
換股後 EPS = 合併後總盈餘 ÷ 合併後總股數。若市場認為無綜效,合併後總價值 = 兩家市值之和,本益比會被「攤平」到中間。
詳解 (a)
  1. Butter 為主併方,發新股給 Bread 股東:新股 = 73,000 ÷ 3 = 24,333.33 股
  2. 合併後總股數 = 146,000 + 24,333.33 = 170,333.33 股
  3. 合併後盈餘 = 210,000 + 630,000 = 840,000 → EPS = 840,000 ÷ 170,333.33 = $4.93
  4. 無綜效時合併後總值 = Butter 市值 + Bread 市值 = 14.4×630,000 + 7.2×210,000 = 9,072,000 + 1,512,000 = 10,584,000
  5. 合併後股價 = 10,584,000 ÷ 170,333.33 = $62.14;本益比 = 62.14 ÷ 4.93 = 12.60

  1. Butter 取得 Bread 的成本 = 發出的新股價值 = 24,333.33 × 62.14 ≈ 1,512,000,恰等於 Bread 獨立市值。
  2. → 在零綜效下 NPV = 1,512,000 − 1,512,000 = 0。
  3. 因此 Butter 必須相信綜效 > 0,這筆交易對它才有正的 NPV、才值得進行。
答案(a) EPS $4.93、股價 $62.14、本益比 12.60 (b) 須相信綜效 > 0
