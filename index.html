線性內插查 N(x)

Black‑Scholes 必用 · 試算工具
為什麼要內插? 常態分配表只列到小數第 2 位(如 N(0.62)、N(0.63)), 但你算出的 d₁、d₂ 通常有 4 位(如 0.6278)。 內插就是「在兩個表值之間,照比例抓中間的值」。
內插公式
N(x) = N(x₀) + w × [ N(x₁) − N(x₀) ] x₀ = 把 x 無條件捨去到小數第 2 位 (下界) x₁ = x₀ + 0.01 (上界) w = (x − x₀) / 0.01 = x 的第 3、4 位小數 (權重 0~1)
課本範例
正值:N(0.6278) = N(0.62) + 0.78×[N(0.63)−N(0.62)] = 0.7324 + 0.78×(0.7357−0.7324) = 0.7350
負值:N(−0.1234) = N(−0.12) − 0.34×[N(−0.12)−N(−0.13)] = 0.4522 − 0.34×(0.4522−0.4483) = 0.4509
小技巧:負值也能用對稱性 N(−x) = 1 − N(x) 反查正表,結果一樣。

13.1用 CAPM 求權益成本
題目
某公司普通股的 β 係數為 1.07。目前無風險利率為 3.4%,市場投資組合的預期報酬率為 11%。請以資本資產定價模型(CAPM)計算該公司的權益資金成本 RE。
(English) The company's common stock has a beta of 1.07. The risk-free rate is 3.4 percent and the expected return on the market is 11 percent. Using the CAPM, what is the company's cost of equity capital?
觀念
CAPM 說明:股東願意承擔風險,因此要求的報酬 = 完全無風險時能拿到的報酬(Rf),再加上「承擔這檔股票系統風險」的補償。補償 = β ×(市場風險溢酬)。β 衡量個股報酬相對整體市場波動的敏感度。市場風險溢酬 = 市場報酬 − 無風險利率。
公式
RE = Rf + β × ( Rm − Rf )
Rf = 無風險利率 · Rm = 市場預期報酬 · β = 系統風險係數
詳解
  1. 先算市場風險溢酬:Rm − Rf = 11% − 3.4% = 7.6%
  2. 乘上 β:1.07 × 7.6% = 8.132%
  3. 加回無風險利率:RE = 3.4% + 8.132% = 11.532%
FC-100V 按法
COMP 模式
3.4+1.07×(11−3.4)=
顯示 11.532
答案RE = 11.5320% ≈ 11.53%
13.5計算加權平均資金成本 WACC
題目
某公司的目標資本結構為:權益佔總市值 70%、負債佔 30%。權益資金成本 RE = 11.3%,稅前負債成本 RD = 5.9%,公司稅率 Tc = 23%。請計算 WACC。
(English) A firm has a target capital structure of 70 percent equity and 30 percent debt. The cost of equity is 11.3 percent, the pretax cost of debt is 5.9 percent, and the tax rate is 23 percent. What is the company's WACC?
觀念
WACC 是公司整體的資金成本:把權益與負債各自的成本依市值權重加權平均。關鍵:利息可抵稅,實際負擔的是稅後 RD(1−Tc);股利不能抵稅,權益成本不打折。
公式
WACC = (E/V)·RE + (D/V)·RD·(1 − Tc)
E/V = 權益權重 · D/V = 負債權重 · Tc = 稅率
詳解
  1. 權益貢獻 = 0.70 × 11.3% = 7.91%
  2. 稅後負債成本 = 5.9% × (1−0.23) = 5.9% × 0.77 = 4.543%
  3. 負債貢獻 = 0.30 × 4.543% = 1.3629%
  4. 相加:WACC = 7.91% + 1.3629% = 9.2729%
FC-100V 按法
COMP 模式
0.7×11.3+0.3×5.9×0.77=
顯示 9.2729
答案WACC = 9.2729% ≈ 9.27%
13.7由 WACC 反推資本結構權重
題目
某公司 WACC = 8.4%,權益成本 RE = 11%,稅前負債成本 RD = 5.8%,稅率 Tc = 25%。求負債佔總值比 D/V、權益佔總值比 E/V,以及負債權益比 D/E。
(English) A company has a WACC of 8.4 percent, a cost of equity of 11 percent, and a pretax cost of debt of 5.8 percent. The tax rate is 25 percent. Find the firm's debt-to-value ratio (D/V), equity-to-value ratio (E/V), and debt-equity ratio (D/E).
觀念
WACC 公式有兩個權重,但 E/V + D/V = 1,只剩一個未知數。設 D/V = x,E/V = 1−x,代入解一元一次方程式。
公式
WACC = (1 − x)·RE + x·RD·(1 − Tc)
E/V = 1 − x
D/E = (D/V) ÷ (E/V)
x = D/V(待解的未知數)
詳解
  1. 設未知數並代入:稅後負債成本 = 5.8%×0.75 = 4.35%
    8.4 = (1−x)(11) + x(4.35)
  2. 展開化簡:8.4 = 11 − 11x + 4.35x = 11 − 6.65x
  3. 解 x:6.65x = 2.6 → x = 2.6/6.65 = 0.3910(D/V)
  4. 其餘權重:E/V = 1 − 0.3910 = 0.6090;D/E = 0.3910/0.6090 = 0.6420
FC-100V 按法
COMP 模式
(11−8.4)÷(11−5.8×0.75)=
顯示 0.3910(= D/V);再 0.3910÷0.6090 = 0.6420
答案D/V = 0.3910 · E/V = 0.6090 · D/E = 0.6420
13.10反求稅前負債成本與權益成本
題目
某公司目標負債權益比 D/E = 0.65,稅率 23%,WACC = 10.4%。(a) 若權益成本 RE = 14%,求稅前負債成本 RD。(b) 若已知稅後負債成本為 5.8%,求權益成本 RE。
(English) A firm has a target debt-equity ratio of 0.65, a tax rate of 23 percent, and a WACC of 10.4 percent. (a) If the cost of equity is 14 percent, what is the pretax cost of debt? (b) If instead the aftertax cost of debt is 5.8 percent, what is the cost of equity?
觀念
同一條 WACC 公式,已知其他項就能反解任一項。先把 D/E 換權重:D/E=0.65 → 共 1.65 → D/V = 0.65/1.65,E/V = 1/1.65。
公式
WACC = (E/V)·RE + (D/V)·RD·(1 − Tc)
D/V = 0.65 / 1.65 = 0.3939
E/V = 1 / 1.65 = 0.6061
詳解 (a) 求稅前 RD
  1. 權重:D/V = 0.3939,E/V = 0.6061
  2. 代入:10.4 = 0.6061×14 + 0.3939×RD×0.77 = 8.4848 + 0.30333·RD
  3. 求解:0.30333·RD = 1.9152 → RD = 6.3137%
詳解 (b) 求 RE(已知稅後負債成本 5.8%)
  1. 稅後負債成本已給 = 5.8%,直接代入:10.4 = 0.6061·RE + 0.3939×5.8
  2. 計算:10.4 = 0.6061·RE + 2.2848
  3. 求解:0.6061·RE = 8.1152 → RE = 13.39%
答案(a) 稅前 RD ≈ 6.31% · (b) RE ≈ 13.39%
13.13用各專案的 CAPM 報酬取代單一門檻
題目
某公司一律用 12% 作為投資門檻。無風險利率 4%,市場報酬 12%。四個專案的 β 為:W(0.83)、X(0.92)、Y(1.09)、Z(1.35)。(a) 用 12% 門檻會接受哪些?(b) 用各自 CAPM 要求報酬應接受哪些?(c) 單一門檻會造成什麼錯誤?
(English) A firm uses a single 12 percent hurdle rate for all projects. The risk-free rate is 4 percent and the market return is 12 percent. Four projects have betas of 0.83 (W), 0.92 (X), 1.09 (Y), and 1.35 (Z), each with its own IRR. (a) Using the 12 percent hurdle, which are accepted? (b) Using each project's CAPM required return, which should be accepted? (c) What errors does the single hurdle rate cause?
觀念
不同專案風險(β)不同,門檻應因案而異:各專案用自己的 β 算 CAPM 要求報酬,IRR > 自身要求報酬才接受。若全用同一門檻,會「高風險爛案被誤收、低風險好案被誤拒」。
公式
要求報酬 = Rf + β × ( Rm − Rf ) = 4% + β × 8%
詳解 — 各專案 CAPM 要求報酬
  1. 市場風險溢酬 = 12% − 4% = 8%
  2. W:4% + 0.83×8% = 10.64%
  3. X:4% + 0.92×8% = 11.36%
  4. Y:4% + 1.09×8% = 12.72%
  5. Z:4% + 1.35×8% = 14.80%
專案βCAPM 要求報酬vs 12%vs 自身門檻
W0.8310.64%低於低於
X0.9211.36%低於高於 ✓
Y1.0912.72%高於高於 ✓
Z1.3514.80%高於低於
判斷
  1. (a) 12% 門檻 → 接受 IRR>12% 的:Y、Z
  2. (b) 正確(IRR > 各自 CAPM) → 接受:X、Y
  3. (c) 錯誤:X 被錯拒(IRR 高於自身 11.36% 卻低於 12%);Z 被錯收(IRR 高於 12% 卻低於自身 14.80%,風險沒被補償)。
答案(a) Y, Z · (b) X, Y · (c) X 被錯拒、Z 被錯收

18.1全權益最高買價 + APV
題目
Benton 公司考慮購入一支 25 輛車的車隊,直線折舊 5 年(殘值 0)。每年稅前折舊前利潤(PBTD)$225,000,稅率 21%,折現率(全權益權益成本)14%。(a) 若全權益融資,最高願付多少買價?(b) 若以 $700,000 購入並舉借 $450,000、利率 8% 的只付息負債,求 APV。
(English) Benton Company is considering buying a fleet of 25 cars to be depreciated straight-line to zero over 5 years. The fleet generates pretax-before-depreciation earnings (PBTD) of $225,000 per year. The tax rate is 21 percent and the all-equity discount rate is 14 percent. (a) If the purchase is all-equity financed, what is the most the firm should pay? (b) If the firm pays $700,000 and finances $450,000 with interest-only debt at 8 percent, what is the APV?
觀念
APV = ① 假裝全用權益的基礎 NPV + ② 融資副效果(利息稅盾現值)。每年無槓桿現金流 UCF = 稅後營業利潤 + 折舊稅盾。(a) 技巧:折舊 = 買價/5,買價未知,故把 P 當變數令 Base NPV = 0 解最高價。
公式
UCF = PBTD·(1 − Tc) + 折舊·Tc
基礎 NPV = −成本 + UCF·PVIFA(RE, n)
年利息稅盾 = 負債 × 利率 × Tc
APV = 基礎 NPV + 年利息稅盾·PVIFA(RD, n)
詳解 (a) 全權益最高買價
  1. 查因子 PVIFA(14%, 5) = 3.4331
  2. UCF 寫成 P 的函數(折舊 = P/5):UCF = 225,000×0.79 + (P/5)×0.21 = 177,750 + 0.042P
  3. 令 Base NPV = 0:P = (177,750 + 0.042P) × 3.4331
  4. 展開:P = 610,233.5 + 0.14419P
  5. 解 P:0.85581P = 610,233.5 → P = $713,048
詳解 (b) APV(買價 $700,000、負債 $450,000)
  1. 折舊 = 700,000/5 = 140,000/年
  2. UCF = 225,000×0.79 + 140,000×0.21 = 177,750 + 29,400 = 207,150
  3. 基礎 NPV = −700,000 + 207,150×3.4331 = $11,167
  4. 年利息稅盾 = 450,000×8%×21% = 7,560
  5. 稅盾現值(用 8% 折現,PVIFA(8%,5)=3.9927)= 7,560×3.9927 = $30,185
  6. APV = 11,167 + 30,185 = $41,352
FC-100V 按法 ① 算基礎 NPV(CASH 模式)
CASH 模式
I%=14→Csh:CF0=−700000→CF1~CF5=207150→NPVSOLVE
NPV ≈ 11,167(CF1~CF5 連按 5 次 207150 =)
FC-100V 按法 ② 算稅盾年金現值(CMPD 模式)
CMPD 模式 P/Y=1 C/Y=1
n=5→I%=8→PMT=−7560→FV=0→SOLVE→PV
PV ≈ 30,185;APV = 11,167 + 30,185 = 41,352
答案(a) 最高買價 ≈ $713,048 · (b) APV ≈ $41,352
18.5用 unlevered β 還原各公司 RE
題目
同產業無槓桿(資產)βA = 1.05。無風險利率 3.2%,市場風險溢酬 8.1%,稅率 21%,負債 β = 0。North 部門 D/E ≈ 0.5135,South 部門 D/E ≈ 1.9474。求兩部門各自的權益成本 RE。
(English) Two divisions share an unlevered (asset) beta of 1.05. The risk-free rate is 3.2 percent, the market risk premium is 8.1 percent, the tax rate is 21 percent, and debt beta is assumed zero. North has a D/E of about 0.5135 and South about 1.9474. Find each division's cost of equity.
觀念
負債放大股東風險,levered 權益 β 比資產 β 大。先用 levering 公式把資產 β 依各部門 D/E 加槓桿,再代入 CAPM 求 RE。
公式
βE = βA × [ 1 + (1 − Tc) × (D/E) ]
RE = Rf + βE × (市場風險溢酬)
假設負債 β = 0
詳解 — North(D/E = 0.5135)
  1. 加槓桿:βE = 1.05 × [1 + 0.79×0.5135] = 1.05 × 1.4057 = 1.4760
  2. CAPM:RE = 3.2% + 1.4760×8.1% = 15.16%
詳解 — South(D/E = 1.9474)
  1. 加槓桿:βE = 1.05 × [1 + 0.79×1.9474] = 1.05 × 2.5384 = 2.6653
  2. CAPM:RE = 3.2% + 2.6653×8.1% = 24.79%
答案North RE ≈ 15.16% · South RE ≈ 24.79%
18.6補貼貸款的 NPV(含發行成本)
題目
某公司取得 10 年期、利率 5.8% 的貸款,毛額 $5,300,000,發行成本為毛額的 2.5%,稅率 21%。利息每年付、本金到期一次還。(a) 不含發行成本的 NPV?(b) 含發行成本(分 10 年攤銷)的 NPV?
(English) A firm obtains a 10-year, 5.8 percent loan with gross proceeds of $5,300,000. Flotation costs are 2.5 percent of gross proceeds and the tax rate is 21 percent. Interest is paid annually and principal is repaid at maturity. (a) What is the NPV of the loan excluding flotation costs? (b) What is the NPV including flotation costs amortized over 10 years?
觀念
公平定價的貸款,用稅後現金流以稅後負債成本折現,NPV 剛好 = 0。讓 NPV 變負的是發行成本:實拿毛額 − 發行成本,卻按全額付息還本;發行成本分年攤銷有少量稅盾,但抵不過成本本身。
公式
稅後利率 = RD × (1 − Tc)
稅後利息 = 本金 × RD × (1 − Tc)
NPV = +毛額 − 稅後利息·PVIFA − 本金·PVIF (以稅後利率折現)
發行成本年稅盾 = (發行成本 ÷ 年數) × Tc
詳解 (a) 不含發行成本
  1. 稅後負債利率 = 5.8%×0.79 = 4.582%
  2. 每年稅後利息 = 5,300,000×5.8%×0.79 = 242,846
  3. 折現(PVIFA≈7.8809,PVIF≈0.6389):NPV = 5,300,000 − 242,846×7.8809 − 5,300,000×0.6389 ≈ $0
詳解 (b) 含發行成本
  1. 發行成本 = 2.5%×5,300,000 = 132,500
  2. 每年攤銷 = 13,250 → 稅盾 = 13,250×0.21 = 2,782.50/年
  3. 稅盾現值 = 2,782.50×7.8809 = 21,929
  4. NPV = 0 − 132,500 + 21,929 = −$110,571
FC-100V 按法(用 CASH 模式驗證 a 的 NPV=0)
CASH 模式
I%=4.582→CF0=+5300000→CF1~CF9=−242846→CF10=−5542846→NPVSOLVE
NPV ≈ 0(CF10 = 利息 242,846 + 本金 5,300,000)
答案(a) NPV = $0 · (b) NPV ≈ −$110,571
18.7全權益專案的 NPV
題目
Jimenez 公司為全權益公司,權益成本 11.2%(題目另給無風險利率 3.4%)。專案需投資 $11.6M,直線折舊 6 年,每年「營收 − 費用」= $3.5M,稅率 23%。求 NPV 並判斷是否接受。
(English) Jimenez Company is all-equity with a cost of equity of 11.2 percent (a risk-free rate of 3.4 percent is also given). A project costs $11.6 million, is depreciated straight-line over 6 years, and generates revenues minus expenses of $3.5 million per year. The tax rate is 23 percent. Find the NPV and decide whether to accept.

  4. NPV = −11,600,000 + 3,139,666.67×4.2063 = +$1,606,308 → 接受

18.8永續現金流 + WACC
題目
National Electric 評估需投資 $41M 的專案,產生永續無槓桿現金流 $3.1M/年。稅前負債成本 5.1%、權益成本 10.3%、目標負債佔比 D/V = 60%、稅率 21%。用 WACC 求 NPV。
(English) National Electric is evaluating a $41 million project that produces perpetual unlevered cash flows of $3.1 million per year. The pretax cost of debt is 5.1 percent, the cost of equity is 10.3 percent, the target debt-to-value ratio is 60 percent, and the tax rate is 21 percent. Using the WACC, find the NPV.
觀念
無槓桿永續現金流現值 = 現金流 ÷ WACC(永續年金)。WACC 已內含負債稅盾,直接用它折現即可。
公式
WACC = (E/V)·RE + (D/V)·RD·(1 − Tc)

  1. T 對 B 的價值 = 28,500 + 17,000 = 45,500
  2. (a) 現金 $23/股:成本 = 1,500×23 = 34,500;NPV = 45,500 − 34,500 = $11,000
  3. (b) 現金後每股價 = (339,200 − 34,500 + 45,500) ÷ 6,400 = 350,200 ÷ 6,400 = $54.7188
  4. (c) 溢價 = 34,500 − 28,500 = $6,000
  5. (d) 股票 1 換 2:新發 B 股 = 1,500 ÷ 2 = 750;合併後股數 = 7,150;合併後總值 = 339,200 + 28,500 + 17,000 = 384,700;每股價 = 384,700 ÷ 7,150 = $53.8042
  6. (e) 換股 NPV:成本 = 750 × 53.8042 = 40,353.15;NPV = 45,500 − 40,353.15 = $5,146.85
答案(a) $11,000 (b) $54.7188 (c) $6,000 (d) $53.8042 (e) $5,146.85
