線性內插查 N(x)

Black‑Scholes 必用 · 試算工具
為什麼要內插? 常態分配表只列到小數第 2 位(如 N(0.62)、N(0.63)), 但你算出的 d₁、d₂ 通常有 4 位(如 0.6278)。 內插就是「在兩個表值之間,照比例抓中間的值」。
內插公式
N(x) = N(x₀) + w × [ N(x₁) − N(x₀) ] x₀ = 把 x 無條件捨去到小數第 2 位 (下界) x₁ = x₀ + 0.01 (上界) w = (x − x₀) / 0.01 = x 的第 3、4 位小數 (權重 0~1)
課本範例
正值:N(0.6278) = N(0.62) + 0.78×[N(0.63)−N(0.62)] = 0.7324 + 0.78×(0.7357−0.7324) = 0.7350
負值:N(−0.1234) = N(−0.12) − 0.34×[N(−0.12)−N(−0.13)] = 0.4522 − 0.34×(0.4522−0.4483) = 0.4509
小技巧:負值也能用對稱性 N(−x) = 1 − N(x) 反查正表,結果一樣。

13.5求 WACC權益權重 70%、RE=11.3%;負債權重 30%、RD=5.9%;稅率 23%

  2. 稅後負債 = 0.30 × 5.9% ×(1−0.23) = 0.30 × 5.9% × 0.77 = 1.3629%
  3. WACC = 7.91% + 1.3629% = 9.2729%

13.7求資本結構權重負債市值與權益市值,算 D/V、E/V、D/E
觀念
資金成本一律用市值權重(非帳面值)。V = D + E。
公式
D/V = D/(D+E) ; E/V = E/(D+E) ; D/E = D/E
解題步驟
  1. D/V = 0.3910(39.10%)
  2. E/V = 1 − 0.3910 = 0.6090
  3. D/E = 0.3910 / 0.6090 = 0.6420
答案D/V = 0.3910 · E/V = 0.6090 · D/E = 0.6420

18.1全權益最高買價 + APV(a) 全權益融資最高可付價;(b) 含 $450,000 負債的 APV
觀念
APV = 全權益基礎 NPV(Base NPV)+ 融資副效果(主要是負債利息稅盾現值)。全權益最高買價:讓 base NPV = 0 的價格。折舊用直線法、折舊稅盾 = 折舊 × Tc。
公式
UCF = PBTD·(1−Tc) + 折舊·Tc APV = −成本 + UCF·PVIFA + 利息稅盾·PVIFAD
解題步驟
  1. (a) 設買價 P,折舊 = P/5,UCF = PBTD(1−0.42... 依題稅率) + (P/5)Tc。令 NPV=0,解出最高價 P ≈ $713,048(查表 PVIFA;全精度約 $713,043)。
  2. (b) 成本 $700,000 → 折舊 = 140,000,UCF = 207,150;以 R 折現得 base NPV ≈ $11,167。
  3. 負債 $450,000、利率 8%、只付息:年利息稅盾 = 450,000 × 0.08 × 0.21 = 7,560;融資 NPV = 7,560 × PVIFA(8%,5)=7,560 × 3.9927 ≈ $30,185。
  4. APV = 11,167 + 30,185 ≈ $41,351。
FC-100V 按法(年金現值因子 PVIFA)
CMPD 模式
n=5→I%=8→PMT=−1→FV=0→SOLVE PV
→ PVIFA = 3.9927(取絕對值)
答案(a) ≈ $713,048 · (b) APV ≈ $41,351

觀念
先取得資產(unlevered)β,再依各公司 D/E 用 levering 公式還原成 levered βE,代入 CAPM 求 RE。假設負債 β=0。
公式
βE = βA · [ 1 + (1−Tc)·(D/E) ] RE = Rf + βE·(市場溢酬)

  2. South:D/E = 1.9474 → βE = 2.6653 → RE = 3.2% + 2.6653×8.1% = 24.79%
答案North RE ≈ 15.16% · South RE ≈ 24.79%

23.1員工選擇權評價與決策Cheryl:S=E=50, R=6%, t=5, σ=53%,35,000 股
觀念
公司給的股票選擇權用 BS 評價(履約價=現價即 at‑the‑money)。再與現金 bonus 比較。對員工本人而言,因無法分散、不能避險,BS 會高估其主觀價值。
解題步驟
  1. σ√t = 0.53×√5 = 1.1851
  2. d₁ = [ln(1) + (0.06+0.53²/2)×5] / 1.1851 = 0.8457
  3. d₂ = 0.8457 − 1.1851 = −0.3394
  4. 內插 N(d₁)=0.8011,N(d₂)=0.3671
  5. e−Rt = e−0.3 = 0.740818
  6. C = 50×0.8011 − 50×0.740818×0.3671 ≈ $26.46
  7. 總價值 = 26.46 × 35,000 ≈ $926,006
決策
  1. (b) 選擇權總值 $926,006 > 現金 bonus $750,000 → 若風險中立,建議選「選擇權」。
